# foamToPython Workspace Instructions for VS Code Copilot

## Python Dependency Management with uv

This project uses **uv** for managing Python virtual environments and dependencies. Always follow these practices when working with Python code in this workspace.

### Before Running Python Code

1. **Always configure the Python environment first** using the `configure_python_environment` tool before executing any Python scripts or code snippets.
2. The tool automatically detects and uses the uv-managed virtual environment configured in this workspace.
3. Never run raw `python` commands; use the configured Python environment.

### Installing Dependencies

When dependencies need to be added or updated:

```bash
uv pip install <package-name>
```

For development dependencies:
```bash
uv pip install -e .[dev]
```

### Running Python Code

- Use the configured Python environment via `configure_python_environment` tool before executing any Python operations.
- For running scripts: Use `run_in_terminal` with the Python executable from the configured environment.
- For running code snippets: Use `mcp_pylance_mcp_s_pylanceRunCodeSnippet` after configuring the environment.

### Key Dependencies

- **numpy**: Core numerical computing (required)
- **pytest**: Testing framework (dev dependency)
- **foamlib**: For examples (optional dependency)

### Project Structure

- `src/foamToPython/`: Main package source code
  - `readOFField.py`: Field reading functionality
  - `readOFList.py`: List reading functionality
  - `_field_parser.py`: Field parsing utilities
  - `_field_writer.py`: Field writing utilities
- `tests/`: Test suite using pytest
- `examples/`: Example scripts demonstrating package usage
- `pyproject.toml`: Project metadata and dependencies

### Testing

Run tests using the configured environment:
```bash
uv run pytest
```

Or:
```bash
pytest tests/
```

### Notes

- The project uses setuptools as the build backend
- Python 3.8+ is required
- All virtual environment management is handled by uv; do not manually create venv or conda environments
